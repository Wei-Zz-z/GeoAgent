# 快报与区县地图接入说明

本次提供模板快报和区县地图两组功能，以及对应的本机 stdio MCP 接口。Word输出、标准问题查询和区县统计已测试；PDF依赖目标机器转换环境，自由问数结果不能作为已核验结论。

## 安装与运行

在backend目录执行`uv sync --locked`，根据`.env.example`创建本机`.env`。数据库连接和模型密钥只填在本机环境文件，不提交仓库。运行账号只授予必要的数据库只读权限。

后端：`uv run --env-file .env uvicorn geoagent.server.app:app --host 127.0.0.1 --port 8000`。

前端：在frontend目录执行`npm ci`和`npm run dev`。不同端口部署时，前端启动前用环境变量`GEOAGENT_DEV_API_TARGET`指定后端地址，不改共享实例。

## 模板快报

- 上传不超过10MB的DOCX，解析原文、表格、样式、待填位置和图表锚点，显示待填位置数及问题组数。
- 已核验的快报删除统计数值原件、界面下载的问题库示例、师兄挖空原件，使用各自固定统计与回填映射；近似文件不能冒充已核验原件。
- 其他模板采用动态链路：解析后核对候选，明确选择标准问题，再执行受控SQL。候选匹配分不是正确率，不能仅凭分数认定统计口径一致。
- 实际查询结果保存在工作流中，用于正文、表格及图表回填；不可靠的对应关系保留“待核实”，不以零替代缺失值。
- 自由问数会向当前配置的模型发送问题和汇总结果，输出标为“未命中标准问题库，仅供参考”。目前只支持已验证的单值与单位绑定，复杂回答不保证自动回填。
- 日期按查询开始的系统时间更新，监测期仍按数据所属期；面积按模板口径换算，数字不使用千分位逗号。
- Word内置图表需要支持其显示的文档客户端。网页预览及无Word服务器上的显示兼容性需另行验收。
- PDF转换失败时保留Word并返回单独错误；不要把本机转换成功当作服务器PDF环境已解决。

## 区县地图

网页入口`/?view=county-map`。选择变化图斑ZIP和可选行政区边界ZIP，生成后切换饼图、柱状图，点击区县查看统计明细。

输入为一套带坐标系的Shapefile ZIP，图斑需包含XZQDM、XMC、TBLX、MJ等必要属性，边界需包含XZQDM、XZQMC和多边形几何。缺单位、代码、坐标系或关联冲突时拒绝生成。

统计按区县汇总变化图斑；面积使用MJ平方米折亩，MU用于单位一致性校验，不重复累加。提供行政区边界时按XZQDM关联；定位点是边界内代表点，不保证是行政中心。没有边界时显示图斑覆盖范围，不称其为完整行政区。

当前数据通路用于同门提供的模拟图斑，并明确标注模拟数据；不应以模拟值作为业务结论。本次不包含任意数据库查询结果自动关联地图的能力。原ZIP只读，几何修复仅用于显示并保留警告。

## 两个MCP

在backend目录分别启动：

```text
uv run python -m geoagent.mcp_server
uv run python -m geoagent.county_mcp_server
```

由MCP客户端作为本地子进程连接，不需要先启动前端。客户端应设置工作目录为backend，通过环境变量提供本机配置。文件路径指服务所在机器的路径，输出目录需可写。本机stdio不等于远程网络服务，本次没有开放远程MCP端口或实现认证。

快报发现7个工具，动态调用顺序如下：

1. `start_template_workflow(template_path)`解析文件，取得工作流编号。
2. `query_template_standard(workflow_id, question_id, library_id)`执行明确选择的标准问题。
3. 可选`query_template_free`执行自由问数，按参考结果处理。
4. `generate_template_report(workflow_id, include_pdf=false)`按实际保存的结果输出；未知位置保留待核实。

另有`inspect_report_template`用于只读查看，`generate_client_briefing`及`generate_supported_briefing`用于已核验原件的固定生成。服务重启后需重新解析；网页与MCP不共享进程内工作流编号。

地图工具`create_county_chart_map(vector_zip_path, boundary_zip_path=None)`返回统计元数据与本机地图JSON路径。完整几何不塞入模型上下文；需能读取该输出文件的地图客户端进行渲染。

## 测试与支持边界

在backend目录运行`uv run pytest`。前端运行`npm run build`。两个真实stdio进程的工具发现可用`uv run python ../scripts/smoke_dual_mcp_stdio.py`核验，不调用数据库或模型。

真实矢量手动验收：`uv run python ../scripts/smoke_county_mcp.py <变化图斑ZIP> <新输出JSON> --boundary <行政区边界ZIP>`。选择新的输出路径，避免覆盖旧验收结果。

2026年10月8日本机验收：8组标准问题查询成功，回填12个正文数值、2张表格、2个内置图表；1处已有查询但未可靠绑定，2处自由问数未执行，均保留待核实。地图验收102321条模拟图斑、90个区县，定位点全部位于对应输出几何内。三份固定原件、目标机器PDF和干净安装应在交付环境分别复测。

知识库基础模块是当前运行依赖，但本提交不附向量索引或评测实验，不声称语义检索准确率已经验收。密钥、业务数据、原始矢量ZIP、生成报告、截图和个人工作记录均不入库。
