# 养老设施步行15分钟居住用地覆盖指标

本轮仅接入与养老设施直接相关的指标，不接入医疗、体育、公园等其他设施指标。原有道路累计长度、概略覆盖面积、历史边界相交数和2020年总人口估算继续作为辅助统计。

依据《城镇国土空间监测指标研究项目成果报告》5.4.3“宜居生活—公共服务”中的“社区养老设施步行15分钟覆盖率”：

> 15分钟步行范围覆盖的居住用地面积／同一研究区居住用地总面积×100%。

分子需使用全部适用社区养老设施的15分钟步行范围并集，不能重复累计重叠覆盖。分母需使用同一研究区内全部居住用地面积，不能用行政区面积、人口、社区数量或仅有变化图斑的居住用地面积替代。

## 本轮输出

- `community_elder_15min_coverage`：原文区域指标，当前数值保持`null`。除了缺少居住用地，现有机构目录尚未核实社区养老类型及完整集合，概略面精度也未核验，不能由单设施试算推导全区指标。
- `single_facility_residential_15min`：本设施15分钟居住用地覆盖率试算。仅当本轮为步行、实际包含15分钟档且居住用地可用时产生数值。它使用单设施概略面，不等同于原文区域指标。
- 每档结果保存`residential_covered_area_m2`、`residential_total_area_m2`和`residential_coverage_percent`，供结构化展示及核对。模型摘要按已有规则将面积换算为亩。
- 结果中的`residential_reference`保存数据状态和来源；`monitoring_indicators`保存名称、公式、范围、数值、状态和缺项。模型、地图及指标表使用同一份记录。

数据缺失、坐标未声明、边界不可用或分母为零时，数值为空并说明原因，不能显示为0%。已知有效分母且覆盖与居住用地确实不相交时，0%才是可计算的结果。驾车或其他时长不会被冒充为15分钟步行指标。

## 可选数据配置

在`GEOAGENT_ELDER_DATA_DIR`目录放置`residential_land.geojson`。该文件须已经筛选为研究区完整的居住用地面，不读取或猜测地类字段；不能直接放入混合地类图层。文件为GeoJSON FeatureCollection，所有要素须为非空Polygon或MultiPolygon，并明确声明坐标系：

```json
{
  "type": "FeatureCollection",
  "source": "填写数据来源、年份及居住用地筛选口径",
  "crs": {
    "type": "name",
    "properties": {"name": "EPSG:4326"}
  },
  "features": []
}
```

示例的空`features`仅说明结构，不能用于产生数值。实际要素写入`features`后，程序转换到分析使用的米制坐标系，合并重复面，并与所选研究区边界相交后计算分母。图形修复不能代替来源和地类口径核验。

`calculate_residential_coverage`支持传入多个覆盖面并集去重，便于后续区域统计复用；本轮不自动对全区全部机构批量求解，也不把正式区域指标标为已完成。今后仍需补齐完整社区养老设施、入口和路网核验、覆盖模型及同年份居住用地数据。
